PICA-SR PICA200 post-processing kernels:
  ponuno / PICASR-FSR-for-3DS — https://github.com/ponuno/PICASR-FSR-for-3DS
  Source used with permission from its author. The PICA-SR TEV kernels provide
  the optional native-resolution edge AA and sharpening passes in Graphics.
  The upstream repository does not include a license file; permission was
  granted directly by the author for this project.

Original engine reconstruction and PC port:
  theclub654 / ProjectCane and its contributors
  https://github.com/theclub654/ProjectCane
  Base revision: f77825d6bc9be3f795ead9d140b410fb9c9c22c1
  License note: Upstream ProjectCane contains no root OSI license file in that
  base revision; all upstream rights remain with their respective authors.
  The native 3DS build reuses the world loader, gameplay, collision, animation,
  render submissions, fonts, sound-bank parser, ADPCM decoder, effect scheduler,
  MIDI/AME music sequencing, music envelopes, and BRX/dialogue extraction logic.

On-hardware FMV decoding (FFmpeg 7.1.1 — LGPL v2.1 or later):
  FFmpeg project — https://ffmpeg.org/
  License: GNU Lesser General Public License v2.1 or later (included verbatim
  in packages as LICENSE-FFmpeg-LGPL2.1.txt and tracked at
  platform/3ds/LICENSE-FFmpeg-LGPL2.1.txt).
  ThieviusCTR.3dsx statically links minimal LGPL builds of libavformat,
  libavcodec, and libavutil configured with --disable-everything (enabling only
  the bink, binkaudio_dct, binkaudio_rdft, and mpeg2video decoders; bink and
  mpegvideo demuxers; and the mpegvideo parser) for real-time on-console Bink
  (.bik) and PS2 MPEG-2 (.m2v) cutscene decoding via 3DS Y2R hardware conversion.
  Includes a small patch to libavformat/bink.c (avio_skip for discarded
  AVDISCARD_ALL audio tracks) applied automatically by
  platform/3ds/build_ffmpeg_3ds.py. Per LGPL v2.1, full build and relinking
  scripts (platform/3ds/build_ffmpeg_3ds.py and platform/3ds/build_runtime.py)
  are provided in the repository so users can modify, rebuild, and relink FFmpeg.
  Desktop host ffmpeg/ffprobe are also optionally used by PC asset-preparation
  scripts (extract_all.py, extract_intro.py, convert_ps3_cutscenes.py).

Launcher, startup updater, and native PICA200 texture-coordinate reference:
  Raihwy3 / eyes-of-gold (Eyes of Gold Launcher) and contributors (MIT License)
  https://github.com/Raihwy3/eyes-of-gold
  Reused and adapted its verified GitHub Release startup updater (update_core,
  update_http, update_3ds, and host ASan/UBSan test harness), pinned OpenDSP
  vendor copy, PICA200 texture-coordinate conventions, and dual-screen console
  chrome design.
  Gyro sensor-axis signs and raw-to-degrees-per-second conversion were also
  referenced from Eyes of Gold. ThieviusCTR integrates the resulting angles
  directly with its own binocular/sniper camera and retains stick control.
  Its native_clip/native_world shaders and stereo submission code were also
  referenced for branch-free stereo, initialized vertex outputs, flat-pass
  restoration and keeping display-mode changes outside GPU frames.

Conker3DSRecomp renderer design reference:
  Raihwy3 and contributors — https://github.com/Raihwy3/Conker3DSRecomp
  Referenced tagged HUD routing, isolated console text buffers, and vertically
  supersampled stereo output. The Sly HUD and dialogue rendering here use
  ProjectCane's own batches, fonts, portraits and animation.
